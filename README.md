# business

## 중심 지침

- [PRE-STAGE. 2027년 산업·시장·장비 선행조사 지침](guidelines/PRE-STAGE_2027_산업·시장·장비_선행조사_지침.docx)

업체별 심층분석에 앞서 2027년 국내외 산업·시장·투자·자동화 장비 및 기술 동향을 조사하여,
TPC로보틱스의 영업기회 발굴용 시장·기술 데이터베이스를 구축하기 위한 기준 문서입니다.

- 연결 구조: 산업 → 시장 → 최종 고객사 → 투자 프로젝트 → 장비 제작업체 → 장비 → 공정 → 유닛 → 부품 → TPC 제품
- 조사 대상 7개 산업: 반도체, 디스플레이, 2차전지, 자동차·전장, 일반 자동화·산업기계, 로봇(협동로봇·AMR·휴머노이드), 광학·정밀검사·의료·바이오 자동화
- 결과물 8종 및 선행조사 종료 조건은 지침 문서 10~11항 참조
